# Restaurant Bill Splitter 🍽️

A simple, user-friendly Python command-line application to calculate and split restaurant bills among a group, including GST / Service charge calculation and Indian Rupee (₹) formatting.

---

## Features ✨

- **Indian Rupee (₹) Support:** Formats currency outputs with proper thousand separators and decimals.
- **Flexible GST / Tip Input:** Accepts inputs like `5` or `5%` seamlessly without crashing.
- **Custom Receipt Output:** Generates a clean, restaurant-style formatted summary receipt in the terminal.
- **Group Bill Splitting:** Calculates the exact individual amount payable per person instantly.
